# IDRC4

Specification documents and official implementations of IDRC4, Identifier-usecase Royal-mail Code by 4-State.

IDRC4 is a Barcode System for identifiers, as extension on [RM4SCC](https://en.wikipedia.org/wiki/RM4SCC), with idea of Code-Page.

The specification is [here](https://idrc4.dev-pack.org/spec/) (Current Japanese only yet) 

---

IDRC4 (識別子のための4状態ロイヤルメールコード - Identifier-usecase Royal-mail Code by 4-State) の仕様文書及び公式実装。

IDRC4は、 [RM4SCC](https://ja.wikipedia.org/wiki/RM4SCC) をもとにコードページの概念を加えた、識別子のためのバーコード体系です。

仕様は[ここ](https://idrc4.dev-pack.org/spec/)にあります。
