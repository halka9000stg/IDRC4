# IDRC4 Technical Note 1

## 要件定義と設計指針

必要な要件として次の2点を設定した。
  
- 画像の生成&認識部分は既存のバーコードを流用することで、コストを最小化  
- 識別記号であるため、ASCII英数字といくつかの記号のみ対応していれば十分  
  
この要件のもと、適した既存バーコードとしてRM4SCCを選定した。これを応用して本仕様を策定した。

ここにコードページの概念を導入することで、表現可能な文字を拡張しつつ、RM4SCCの設計の単純さを維持するという方針とした。
  

## 回転操作とページ番号

コードページ [CP1, CP2, CP3] を循環構造としたとき、

左回転 (L) ＝–1 (mod 3)  
   CP1 → CP3 → CP2 → CP1

右回転 (R) ＝+1 (mod 3)  
   CP1 → CP2 → CP3 → CP1

というように状態遷移する。

(ビット演算の左右回転シフトと似た感覚で考えればよい。)

## 英字の両ページにおけるコード割当

制御コードを構造的に簡潔にするため、2行5列を用いて収めた。このため、英字の両ページは元のコード割当から、「A」を(R2, C5)から(R1, C0)に動かして全体的にすっきりするように定めた。
