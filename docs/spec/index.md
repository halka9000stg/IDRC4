# IDRC4 仕様

## 概要

IDRC4 (Identifier-usecase Royal-Mail Code by 4-State) は、識別子を示すためのバーコード仕様である。IDRC4は、 [RM4SCC (Royal Mail 4-State Customer Code)](https://ja.wikipedia.org/wiki/RM4SCC) を元にして、コードページの概念を加えて、その切り替え (シフト / 回転) によってRM4SCCより多くの文字を表現する。

## 符号化可能文字

IDRC4は、ASCII英大文字、同小文字及び同数字、並びにいくつかのASCII記号及びASCII制御文字を収容する。元のRM4SCCと違い、英字は大文字と小文字の区別がある。記号及び制御文字はコード点の割当において列挙しているので詳細は省く。

## 構造

IDRC4は、数字と記号類を収容するコードページ1、英小文字を収容するコードページ2、及び英大文字を収容するコードページ3の3つから構成される文字集合群を持つ。コードページ共通の制御コード範囲が割当てられており、これを用いて着目するコードページを変更する。

バーコード形式は RM4SCC と同じであり、IDRC4とRM4SCCの文字集合のマップを参照してコード点を変換したあと、 RM4SCC の方式に従ってバーコードを生成する。バーコードの認識も同様である。

## コード点の割当

行と列の並び順は [Wikipedia記事「RM4SCC」における「エンコードと内容」節](https://ja.wikipedia.org/wiki/RM4SCC#チェックサム) のものと対応する。

### 制御コード
  
| 行 \ 列 | 1 | 2 | 3 | 4 | 5 | 0 |  
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |  
| 1 | SS1 | SS2 | SS3 | SLL | SLR | -- |  
| 2 | CS1 | CS2 | CS3 | CLL | CLR | -- |  
| 3 | -- | -- | -- | -- | -- | -- |  
| 4 | -- | -- | -- | -- | -- | -- |  
| 5 | -- | -- | -- | -- | -- | -- |  
| 0 | -- | -- | -- | -- | -- | -- |  

- SSn: コードページnへ単字シフト - Single Shift to Code Page n
- CSn: コードページnへ永続シフト - Continuous Shift to Code Page n
- SLL / SLR: 単字左右回転 - Single Left/Right Rotate (–1 / +1 mod 3)
- CLL / CLR: 永続左右回転 - Continuous Left/Right Rotate

### コードページ1: 数字+記号

| 行 \ 列 | 1 | 2 | 3 | 4 | 5 | 0 |  
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |  
| 1 | -- | -- | -- | -- | -- | ␟ |  
| 2 | -- | -- | -- | -- | -- | ␞ |  
| 3 | 0 | 1 | 2 | 3 | 4 | _ |  
| 4 | 5 | 6 | 7 | 8 | 9 | - |  
| 5 | # | $ | % | & | + | . |  
| 0 | = | ? | @ | ^ | ~ | : |

#### 拡張制御 (2種)

- `␟` (ユニット分離)
- `␞` (レコード分離)

#### デリミタ (4種)

- `_` (アンダースコア)
- `-` (ハイフン)
- `.` (ピリオド)
- `:` (コロン)

#### その他 (10種)

- `#`(シャープ)
- `$` (ドル記号)
- `%` (パーセント)
- `&` (アンパサンド)
- `+` (プラス)
- `=` (等号)
- `?` (疑問符)
- `@` (アットマーク)
- `^` (キャレット)
- `~` (チルダ)

### コードページ2: ASCII英小文字
  
| 行 \ 列 | 1 | 2 | 3 | 4 | 5 | 0 |  
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |  
| 1 | -- | -- | -- | -- | -- | a |  
| 2 | -- | -- | -- | -- | -- | b |  
| 3 | c | d | e | f | g | h |  
| 4 | i | j | k | l | m | n |  
| 5 | o | p | q | r | s | t |  
| 0 | u | v | w | x | y | z |

大文字と小文字の区別があること、及び「A」の位置を移動したことを除いて元のRM4SCCの割当と同じである。
